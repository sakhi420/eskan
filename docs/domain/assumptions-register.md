## فرضیات مالی قطعی (غیرقابل تغییر بدون تصمیم صریح)

1. Charge یک تعهد است، Payment وجهِ وصول‌شده است؛ این دو یکسان نیستند.
2. ماندهٔ ساکن = جمع charges قطعی − جمع allocations معتبر − تعدیلات رسمی (reversal).
3. افزایش نرخ قرارداد، صورتحساب‌های گذشته را تغییر نمی‌دهد (snapshot).
4. اسناد posted حذف فیزیکی نمی‌شوند؛ اصلاح با reversal.
5. negative amount برای reversal ممنوع؛ reversal رویداد مستقل با reference است.
