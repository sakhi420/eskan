# گردش‌کار فعلی (Current Workflows) — اسکان

## محدودیت ثبت‌شده

در زمان این سند هیچ گردش‌کار عملیاتیِ موجود یا مشخص‌شدهٔ رسمی از سوی مالک
محصول ارائه نشده است. بنابراین «گردش‌کار فعلی» به‌صورت «ثبت دستی در دفاتر یا
روش‌های غیرمتمرکز» فرض نمی‌شود و چیزی از آن ساخته نمی‌شود. گردش‌کار هدف در
فایل `target-workflows.md` بر اساس دامنهٔ مستندشده طراحی شده است.

این محدودیت صریح به‌عنوان ریسک Q (وابسته به مالک) ثبت شده است.

نکته: عدم وجود گردش‌کار فعلی مستند، مانع تصمیم‌های دامنه‌ای نیست؛
default امن در `assumptions-register.md` اعمال می‌شود.
